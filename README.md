# SQL Analysis

This project's SQL analysis is split into two areas:

- [Budget vs Actual](./budget_vs_actual/README.md) — comparison between planned budget and actual sales by product, year, and price tier.
- [Inventory Risk](./inventory_risk/README.md) — stockout risk, lead time vs safety stock, shelf life, storage costs.

See each folder's README for methodology, key numbers, and insights. SQL queries are in `queries/`.
